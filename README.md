# Vampire: The Masquerade - Bloodlines 2 MO2 Plugin

Basic Games support for the Steam version of Vampire: The Masquerade - Bloodlines 2.

## Install

1. Close Mod Organizer 2.
2. Copy `game_bloodlines2.py` into `<MO2 root>/plugins/basic_games/games/`.
3. Start MO2 and select Bloodlines 2 when configuring an instance. If it is not listed, enable **Show all games** and browse to the game's Steam installation folder.

When creating a new MO2 instance, choose **Portable** if you want a portable setup.

## Notes

- Steam App ID: `532790`.
- Save files are located in `%LOCALAPPDATA%/Bloodlines2/Steam/Saved/SaveGames` and use the `.sav` extension.
- GOG support is not included or tested.
- Profile-specific saves are unsupported. Disable **Use profile-specific save games** in MO2's profile defaults.
